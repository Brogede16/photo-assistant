## Regler

- Valider moderne råd mod Canon EOS 80D, ikke mod nyere spejlløse kameraer.
- Gem startpunkter og intervaller.
- Angiv når en anbefaling afhænger af lys, bevægelse eller motivafstand.
- Canon Camera Connect må kun bruges som guidet fjernudløser/Live View-hjælp, ikke som direkte integreret styring.
